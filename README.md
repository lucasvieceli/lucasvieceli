### 👋 Sobre mim

Sou **Lucas Vieceli**, desenvolvedor full stack com **15 anos de experiência** construindo produtos web e mobile — de e-commerces e marketplaces a aplicativos e sistemas multi-tenant.

- 🧩 Trabalho ponta a ponta: **React / Next.js / React Native** no front, **Node.js / NestJS** no back
- 🛒 Especialidade em **e-commerce, marketplaces e integrações de pagamento**
- 🚀 Cuido também de **Docker, CI/CD e deploy** dos projetos que entrego
- 🏠 Working from home — 🇧🇷 Santa Catarina, Brasil
- 💬 Português e Inglês
